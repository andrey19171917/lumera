## Шаг 1. Загрузить проект

Вариант проще — через сайт:
- [ ] Создать репозиторий на **github.com** → **Add file → Upload files** → перетащить всю папку проекта.

Вариант для терминала:
- [ ] `npm i -g vercel` → в папке проекта `vercel`

---

## Шаг 2. Опубликовать на Vercel

- [ ] Войти на **vercel.com** через GitHub.
- [ ] **Add New → Project → Import** ваш репозиторий → **Deploy**.

---

## Шаг 3. Вписать переменные окружения

Project → **Settings → Environment Variables**. Минимум для старта (Telegram):

| Переменная | Значение |
|-----------|----------|
| `TELEGRAM_BOT_TOKEN` | токен вашего бота @chandelier_unic_bot |
| `TELEGRAM_CHAT_ID` | `256706595` |

Чтобы каталог уходил клиенту на почту — добавить позже (см. `НАСТРОЙКА.md`, Шаг 2):

| Переменная | Значение |
|-----------|----------|
| `RESEND_API_KEY` | ключ из resend.com |
| `MAIL_FROM` | без домена: `LUX <onboarding@resend.dev>` · со своим доменом: `LUX <info@вашдомен.ru>` |
| `MAIL_TO` | `9280365@gmail.com` |
| `CATALOG_URL` | `https://ваш-сайт.vercel.app/catalog.pdf` |

> ✉️ Без своего домена почта работает частично: копии заявок будут приходить **вам** на `9280365@gmail.com` (после подтверждения этого адреса в Resend). А вот авто-каталог **клиентам** на их почту уйдёт только после подключения своего домена в Resend.

> 🔐 Токен вписывается ТОЛЬКО здесь, в Vercel. Никогда — в файлы проекта и не загружать в GitHub.
