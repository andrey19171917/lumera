# LUX — система продаж больших люстр

Готовый сайт + приём заявок в **Telegram** и **на почту** + **автоматическая отправка каталога** клиенту на e-mail.

Всё работает на **бесплатных** тарифах (Vercel, Resend, Telegram). Ниже — пошаговая инструкция запуска. Если что-то непонятно — напишите мне, я проведу по шагам или сделаю за вас.

---

## Что в папке

| Файл | Что это |
|------|---------|
| `index.html` | Разметка сайта (HTML). |
| `css/styles.css` | Все стили и дизайн сайта. |
| `js/app.js` | Скрипты + блок `CONFIG` с вашими контактами (в начале файла). |
| `api/lead.js` | «Мозг» приёма заявок: шлёт заявку в Telegram, на вашу почту и каталог клиенту. |
| `catalog.pdf` | PDF-каталог, который автоматически уходит клиенту. |
| `tools/catalog_generator.py` | Скрипт, которым сделан каталог (можно перегенерировать с вашими данными). |
| `.env.example` | Образец ключей и настроек (что вписать в Vercel). |
| `vercel.json`, `package.json` | Технические файлы для деплоя. Не трогаем. |

## Как это работает (схема)

```
Клиент на сайте  ──>  жмёт «Получить каталог» / «Оставить заявку»
                          │
                          ▼
                   api/lead.js (на Vercel)
                   ├── 📲 уведомление вам в Telegram
                   ├── ✉️ заявка вам на e-mail
                   └── 📄 каталог клиенту на его e-mail
```

## Шаг 1. Telegram-бот (5 минут)

1. В Telegram найдите **@BotFather**, нажмите **Start**.
2. Отправьте `/newbot`, придумайте имя и логин бота (логин заканчивается на `bot`).
3. BotFather пришлёт **токен** вида `1234567890:AAE...` — это `TELEGRAM_BOT_TOKEN`. Сохраните.
4. Теперь узнаём, **куда** слать заявки (ваш `TELEGRAM_CHAT_ID`):
   - Напишите своему боту любое сообщение (например, «привет»).
   - Откройте в браузере ссылку (вставьте свой токен):
     `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
   - Найдите в ответе `"chat":{"id":123456789` — это число и есть `TELEGRAM_CHAT_ID`.

> 💡 Хотите, чтобы заявки видела вся команда? Создайте группу, добавьте туда бота, отправьте в группу сообщение и тем же способом возьмите `id` группы (он будет отрицательным, например `-100123...`).

## Шаг 2. Почта для писем — Resend (10 минут)

Нужно, чтобы письма (заявка вам и каталог клиенту) реально доставлялись.

1. Зарегистрируйтесь на **https://resend.com** (бесплатно, 3000 писем/мес).
2. **Domains → Add Domain** — добавьте ваш домен (например `luuxx.ru`) и пропишите у регистратора домена те DNS-записи (SPF/DKIM), что покажет Resend. Это даёт доставляемость и письма не уходят в спам.
3. **API Keys → Create API Key** — получите ключ вида `re_...` — это `RESEND_API_KEY`.
4. Запомните адрес отправителя, например `info@luuxx.ru` — это `MAIL_FROM`.

> ⏳ Нет своего домена / нет времени на DNS? Для теста можно временно поставить `MAIL_FROM = onboarding@resend.dev`, но тогда письма уходят **только на вашу собственную почту**, подтверждённую в Resend. Для отправки каталога клиентам домен обязателен.

## Шаг 4. Публикация на Vercel (бесплатно)

### Вариант А — через сайт Vercel (проще, без терминала)

1. Заведите аккаунт на **https://vercel.com** (войдите через GitHub).
2. Загрузите эту папку в репозиторий на **github.com** (кнопка **Add file → Upload files**), либо используйте Vercel CLI (вариант Б).
3. В Vercel: **Add New → Project → Import** ваш репозиторий → **Deploy**.
4. Откройте проект → **Settings → Environment Variables** и добавьте переменные из таблицы ниже.
5. **Deployments → ... → Redeploy**, чтобы переменные применились.

### Вариант Б — через терминал (быстрее для опытных)

```bash
npm i -g vercel
cd путь/к/папке
vercel            # первый деплой
# добавьте переменные окружения:
vercel env add TELEGRAM_BOT_TOKEN
vercel env add TELEGRAM_CHAT_ID
vercel env add RESEND_API_KEY
vercel env add MAIL_FROM
vercel env add MAIL_TO
vercel env add CATALOG_URL
vercel --prod     # боевой деплой
```

### Переменные окружения (вписать в Vercel)

| Переменная | Значение | Откуда |
|-----------|----------|--------|
| `TELEGRAM_BOT_TOKEN` | `1234567890:AAE...` | Шаг 1 |
| `TELEGRAM_CHAT_ID` | `123456789` | Шаг 1 |
| `RESEND_API_KEY` | `re_...` | Шаг 2 |
| `MAIL_FROM` | `LUX <info@вашдомен.ru>` | Шаг 2 |
| `MAIL_TO` | `вашапочта@gmail.com` (куда дублировать заявки) | ваша |
| `CATALOG_URL` | `https://ваш-сайт.vercel.app/catalog.pdf` | Шаг 3 |
| `CATALOG_ATTACH` | `false` (в письме кнопка-ссылка) или `true` (PDF вложением) | по желанию |
| `BRAND_NAME` | `LUX` | по желанию |

> После добавления переменных **обязательно сделайте Redeploy** — иначе они не подхватятся.

## Шаг 5. Свой домен (по желанию)

В Vercel: **Settings → Domains → Add** — добавьте `luuxx.ru` и пропишите DNS по инструкции Vercel. После этого сайт откроется на вашем домене, а в `CATALOG_URL` поставьте адрес с вашим доменом.

## Замена данных под себя

**Контакты (телефон, e-mail, Telegram, адрес)** — откройте `js/app.js`, в самом начале найдите `const CONFIG = { ... }` и впишите свои значения. Они автоматически подставятся по всему сайту.

```js
const CONFIG = {
  brand:    "LUX",
  phone:    "+7 (495) 123-45-67",
  phoneRaw: "+74951234567",
  email:    "info@luuxx.ru",
  telegram: "luuxx",           // ваш username без @
  address:  "Московская область, Одинцовский район",
  endpoint: "/api/lead"
};
```

**Фотографии** — в каталоге товаров на сайте сейчас стоят аккуратные заглушки (значок люстры + подпись). Чтобы поставить реальные снимки, замените блоки `.pf` в секции «Портфолио» на `<img src="...">`. Пришлите мне фото — вставлю.

**Каталог PDF** — отредактируйте список моделей и контакты в начале `tools/catalog_generator.py` и запустите `python3 tools/catalog_generator.py`. Либо пришлите данные/фото мне.

## Проверка

1. Откройте опубликованный сайт.
2. В блоке «Каталог придёт вам на почту» введите имя и свою почту → **Получить каталог**.
3. Должно прийти: уведомление в Telegram, письмо вам на `MAIL_TO`, и каталог на указанную почту.
4. Так же проверьте форму «Оставить заявку».

## Если что-то не работает

- **Не приходит в Telegram** — проверьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`; вы должны были хотя бы раз написать боту. После правок — Redeploy.
- **Письма не приходят / в спаме** — домен в Resend должен быть **Verified** (зелёный), DNS-записи прописаны. Без своего домена клиентам письма не уйдут.
- **Каталог не приходит клиенту** — проверьте, что `CATALOG_URL` открывается в браузере и что клиент указал корректный e-mail.
- **Форма пишет «Не удалось отправить»** — значит сайт ещё не на Vercel или переменные не заданы. До деплоя сайт предлагает клиенту написать в Telegram/на почту — это нормальный запасной вариант.
